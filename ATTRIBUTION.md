weapon mastery properties, and the starter monster/item bestiary) is seeded from the
official D&D System Reference Documents, not from copyrighted core rulebooks.

## Data source

The structured catalog data seeded into the database (`packages/server/src/db/seeds/`)
is read from this repository's own `.opencode/skills/dnd5e-srd/data/` reference set,
which is itself sourced from the open-source
[`5e-bits/5e-database`](https://github.com/5e-bits/5e-database) project (MIT-licensed
code/structure, OGL 1.0a / CC-BY-4.0-licensed underlying content per edition). See
`.opencode/skills/dnd5e-srd/ATTRIBUTION.md` for the full breakdown, including exactly
which files come from which edition.
