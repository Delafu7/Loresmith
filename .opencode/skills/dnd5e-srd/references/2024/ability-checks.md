# D20 Tests, Proficiency, and Advantage (SRD 5.2 / 2024 rules)

## D20 Tests

When the outcome of an action is uncertain, the game uses a d20 roll to
determine success or failure. These rolls are called D20 Tests, and they
come in three kinds: ability checks, saving throws, and attack rolls. They
follow these steps:

1. **Roll 1d20.** You always want to roll high. If the roll has Advantage
   or Disadvantage, you roll two d20s, but you use the number from only one
   of them — the higher one if you have Advantage or the lower one if you
   have Disadvantage.
2. **Add Modifiers.** Add the relevant ability modifier, your Proficiency
   Bonus if relevant, and any circumstantial bonuses/penalties.
3. **Compare the Total to a Target Number.** If the total equals or
   exceeds the target number, the D20 Test succeeds. The target number for
   an ability check or saving throw is a **Difficulty Class (DC)**. The
   target number for an attack roll is the target's **Armor Class (AC)**.

### Rolling 20 or 1
- A natural 20 on an attack roll always hits, regardless of AC (a
  **Critical Hit**).
- A natural 1 on an attack roll always misses, regardless of AC.

## Ability Checks

Represents using talent/training to overcome a challenge (forcing a door,
picking a lock, deciphering a cipher...). Named for the ability used:

| Ability      | Make a Check To...                              |
|--------------|--------------------------------------------------|
| Strength     | Lift, push, pull, or break something              |
| Dexterity    | Move nimbly, quickly, or quietly                   |
| Constitution | Push your body beyond normal limits                |
| Intelligence | Reason or remember                                 |
| Wisdom       | Notice things in the environment or in behavior    |
| Charisma     | Influence, entertain, or deceive                   |

**Typical Difficulty Classes**

| Task Difficulty  | DC |
|-------------------|----|
| Very easy          | 5  |
| Easy                | 10 |
| Medium              | 15 |
| Hard                | 20 |
| Very hard           | 25 |
| Nearly impossible   | 30 |

## Saving Throws

An attempt to evade or resist a threat (a fireball, poison gas, a mind-
affecting spell). Named for the ability used:

| Ability      | Make a Save To...                    |
|--------------|-----------------------------------------|
| Strength     | Physically resist direct force            |
| Dexterity    | Dodge out of harm's way                   |
| Constitution | Endure a toxic hazard                     |
| Intelligence | Recognize an illusion as fake             |
| Wisdom       | Resist a mental assault                   |
| Charisma     | Assert your identity                      |

The DC for a saving throw is set by the effect that causes it (e.g. a
spell's save DC) or by the GM.

## Attack Rolls

Hits if the roll (+ modifiers) equals or exceeds the target's AC.

| Ability   | Attack Type                                                |
|-----------|--------------------------------------------------------------|
| Strength  | Melee attack with a weapon or an Unarmed Strike               |
| Dexterity | Ranged attack with a weapon                                   |
| Varies    | Spell attack (ability set by the caster's spellcasting feature)|

**Base AC** = 10 + Dexterity modifier (before armor/items/spells modify it).

## Advantage / Disadvantage

Roll two d20s: use the **higher** with Advantage, the **lower** with
Disadvantage. Multiple sources of Advantage (or of Disadvantage) don't
stack — you still roll only two dice. If a roll has both Advantage and
Disadvantage, they cancel out and you roll one d20 normally.

## Proficiency Bonus

Reflects training. Added to a D20 Test when the creature is proficient in
the relevant skill, saving throw, or item.

| Level or CR | Bonus |
|-------------|-------|
| Up to 4     | +2    |
| 5–8         | +3    |
| 9–12        | +4    |
| 13–16       | +5    |
| 17–20       | +6    |
| 21–24       | +7    |
| 25–28       | +8    |
| 29–30       | +9    |

The bonus never stacks (can't apply it twice to the same roll even if
proficient in multiple relevant things), though it can be doubled by an
explicit feature such as Expertise.

## Actions (main options on your turn)

| Action      | Summary                                                                 |
|-------------|----------------------------------------------------------------------------|
| Attack      | Attack with a weapon or an Unarmed Strike                                   |
| Dash        | Extra movement equal to your Speed for the rest of the turn                 |
| Disengage   | Your movement doesn't provoke Opportunity Attacks this turn                 |
| Dodge       | Attacks against you have Disadvantage; you save Dex with Advantage          |
| Help        | Help another creature's check/attack, or administer first aid              |
| Hide        | Make a Dexterity (Stealth) check                                            |
| Influence   | Charisma or Wisdom check to alter a creature's attitude                     |
| Magic       | Cast a spell, use a magic item, or use a magical feature                    |
| Ready       | Prepare to act in response to a trigger you define                          |
| Search      | Wisdom (Insight, Medicine, Perception, or Survival) check                   |
| Study       | Intelligence (Arcana, History, Investigation, Nature, or Religion) check    |
| Utilize     | Use a nonmagical object                                                     |

**Bonus Actions**: only usable when a feature explicitly grants one; only
one per turn. **Reactions**: instant response to a trigger (e.g. an
Opportunity Attack); only one before the start of your next turn.
